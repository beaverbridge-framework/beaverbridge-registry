BeaverBridge registry vocabulary

https://beaverbridge-framework.github.io/beaverbridge-registry/vocab/

Normalised roles that the same job plays in different Wikibase instances, and the facts the registry records about each instance. Source: bbr.ttl (CC BY 4.0).

TermLabelMeaning
bbr:classKindclass kind'domain' for a class of the things the instance is about (sites, software), 'model' for a class of the data model itself (vocabulary, types, provenance, the roots). Stated by the registry, not by the instance.
bbr:coordinatescoordinatesThe geographic position of the subject, as the source states it (a WKT literal).
bbr:crmBasisbasis of the CRM anchor'source' if the instance states the anchor itself, 'bridge' if the registry states it because the instance does not.
bbr:crmClassCIDOC CRM classThe CIDOC CRM class a class is anchored to. A class without one of its own has the one of its nearest superclass that has one (path bbr:subclassOf*/bbr:crmClass).
bbr:equivalentClassequivalent classThe class item states an IRI of an equivalent class, for example a CIDOC CRM class.
bbr:externalMatchexternal matchA URL of the same thing elsewhere, as the source states it.
bbr:fromInstancefrom instanceThe catalogue record of the instance an entity was harvested from.
bbr:generatorgeneratorThe software and version that wrote the export, as the file's header states it.
bbr:instanceOfinstance ofThe subject is an instance of the object (a class item). In Wikibase this is the property labelled 'instance of', whose number differs between instances.
bbr:partOfpart ofThe subject is a part of the object.
bbr:prefixprefixShort code of the instance, used in front of an identifier when two instances use the same one (fuzzy-sl:Q1, chublets:Q1).
bbr:sha256SHA-256SHA-256 of the harvested export file, as published by the instance.
bbr:sourceTripleCountsource triple countNumber of triples in the harvested export, before the registry left out what it does not use.
bbr:subclassOfsubclass ofThe subject class is a subclass of the object class.
bbr:wikidataEquivalentWikidata equivalentThe Wikidata entity (http://www.wikidata.org/entity/...) that the source names for the subject. Q-numbers and P-numbers given as plain strings are turned into IRIs.
