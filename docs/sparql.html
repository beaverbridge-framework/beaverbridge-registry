Query all instances

The bundle of all registered instances is one RDF graph. The queries below run on it in your browser; edit them and press Run. Questions across instances go through the bbr: roles (instance of, subclass of, part of, …) and never through a P-number, because the numbers differ between Wikibases.

There is no SPARQL endpoint and no server. The bundle is fetched as a static file and parsed in your browser with rdflib under Pyodide, so an archived copy of this repository stays queryable. The Python runtime is loaded from a CDN (jsDelivr) and rdflib from PyPI, once per visit; nothing you type leaves your machine.

1. Which instances are in the registry?

One catalogue record per instance: where it comes from, under which licence, written by which version of wikibase-static, and how large the export was before the registry kept what a search needs.

.rq

2. Which classes have how many items?

The same question in every instance, asked through bbr:instanceOf. The English label of the class is shown; some classes have a second label in another language.

.rq

3. How are the classes related?

Subclass links of all instances, through bbr:subclassOf. Each row is one link from a class to its superclass.

.rq

4. Which Wikibase property stands behind a role?

The registry writes every role as a normalised statement next to the source statement. Asking for the source predicate that carries the same object shows the crosswalk at work: instance of is P1 in one instance and P2 in the other.

.rq

5. Which classes state a CIDOC CRM class?

Only classes that carry an equivalent class IRI themselves are listed. A class without a row here has no anchor in its own instance.

.rq

6. Which items have coordinates?

Items with a position, as the source states it (WKT, longitude first). Only instances with a coordinate property show up.

.rq

7. Which items point to Wikidata?

Plain Q-numbers in the sources are turned into Wikidata IRIs by the bundle step, so this works the same for every instance.

.rq

8. Where do the external matches lead?

Matches are grouped by the host of the URL they point to.

.rq

9. Which properties does each instance define?

All properties with their datatype. The numbers are local to the instance; the label and datatype are what can be compared.

.rq

10. Which labels occur in more than one instance?

Equal names are reported and never merged: the registry only states that two entries share a label, not that they are the same thing. Whether Florian Thiery in both instances is one person is for a person to say.

.rq
